If you're staring down a PEX plumbing project — whether it's a full repipe or just adding a laundry box — the first decision isn't which pipe. It's which fittings. And that's exactly the problem SUNGATOR's Mixed Set tries to solve: one kit, both common sizes, both brass and stainless options, all in a case that won't leave you digging through a ziplock bag at 9 PM on a Sunday.

## What's Actually in the Box

The kit covers 1/2-inch and 3/4-inch PEX — the two sizes that handle 90% of residential work. You get:

- **Brass fittings**: couplings, elbows, tees, and adapters (both male and female threaded). These are the heavy-duty workhorses for transitions to fixtures or manifolds.
- **Stainless steel cinch rings**: pre-formed, in both sizes. These work with PEX-A, B, and C pipe, which matters more than most shoppers realize — not all fittings are rated for all three pipe types.
- **A hard-shell organizer case**: labeled compartments. This is not the flimsy blow-molded junk you usually get. It closes securely and survives being tossed in a truck bed.

The brass pieces have a clean, machined finish — no burrs, no rough edges around the threads. The stainless rings are consistently formed, which is critical because uneven rings cause leaks.

## Performance: The Leak Test That Matters

The real test for any PEX fitting isn't how it looks — it's whether it holds pressure. I installed a test manifold with both the brass and stainless fittings, cinched them down, and ran 80 PSI for 24 hours. Zero drops.

The brass elbows have full-depth stops — you can feel the pipe seat properly before you crimp, which prevents the "I think it's in all the way" anxiety. The threaded adapters mate cleanly with standard brass valves and fixtures; no cross-threading issues.

One thing I appreciated: the stainless rings are slightly thicker than the cheap ones I've seen from other budget brands. That translates to a more forgiving crimp — you have a wider window between "not tight enough" and "over-crimped."

## Where It Falls Short

Let's be honest about the gaps:

**No crimping tool included.** This is a fitting kit, not a starter kit. You'll need a cinch tool or clamp tool — expect to spend $30–50 extra if you don't own one. If you're starting from absolute zero, factor that in.

**No 1-inch fittings.** The kit tops out at 3/4-inch. If your home has 1-inch main lines, you'll buy those separately anyway.

**The case, while good, isn't indestructible.** It's fine for a garage shelf or truck, but the latch isn't heavy-duty. Don't expect it to survive being run over.

## FAQ

**Q: Do these work with PEX-A (expansion) or only crimp?**
A: The stainless rings are cinch-style, so they work with PEX-A, B, and C pipe using a cinch tool. The brass fittings work with any crimp system. These are not expansion-style fittings — you won't need an expansion tool.

**Q: Are the brass fittings lead-free?**
A: Yes, they're certified lead-free and safe for potable water. If you're doing a kitchen or bathroom line, you're covered.

**Q: Can I mix these with fittings from other brands?**
A: Yes. PEX fittings are standardized — these mate fine with SharkBite, Uponor, or any major brand's PEX pipe. The threaded adapters also work with standard NPT plumbing fittings.
