The compound leverage design means you're not fighting the tool — even on 1-inch clamps, the force required stays manageable.

## FAQ

**Does this work with all PEX types?**
Yes. Cinch clamps work with PEX-A, PEX-B, and PEX-C. The tool's jaw range covers 3/8-inch through 1-inch pipe, which handles residential and most light commercial applications.

**Do I need a separate depth gauge?**
For code compliance and peace of mind, yes. This tool doesn't have a built-in gauge, so pick up a PEX cinch clamp depth tool. It's cheap insurance against a hidden leak behind a wall.

**Can this be used for stainless steel clamps only?**
Correct. This is for cinch clamps (also called pinch clamps), not copper crimp rings. If your system uses copper rings, you need a different crimping tool entirely.
