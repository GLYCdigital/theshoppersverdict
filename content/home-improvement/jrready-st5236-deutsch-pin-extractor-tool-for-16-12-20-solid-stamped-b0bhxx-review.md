**FAQ**

**Q: Will this work on AMP or Metri-Pack connectors?**
A: No. These tips are specifically profiled for Deutsch solid/stamped contacts. Using them on other connector brands risks damaging both the tool and the terminal.

**Q: How do I know which gauge tip to use?**
A: Match the tip size to the wire gauge. The color coding helps: red=12, blue=16, black=20. When in doubt, start with the smaller tip and size up if it doesn't seat properly.

**Q: Can I use these on sealed Deutsch connectors?**
A: No. Sealed/machined contacts require a different extraction tool with a hook-style tip. These are strictly for solid stamped terminals.
