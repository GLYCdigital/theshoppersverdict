**Where It Falls Short**

Let's be honest about the tradeoffs:

- **Magnetic base limitations** — If you have an aluminum case (common on higher-end builds), the magnet won't stick. You'll need to use the included adhesive pad instead, which is less clean and harder to reposition.
- **Height adjustment can be finicky** — The twist-lock works well, but getting the exact height requires a few back-and-forth adjustments. It's not a one-try-and-done process.
- **Clearance issues on tight builds** — In cases with limited space between the GPU and the PSU shroud, the base might not fit. Measure before you buy.
