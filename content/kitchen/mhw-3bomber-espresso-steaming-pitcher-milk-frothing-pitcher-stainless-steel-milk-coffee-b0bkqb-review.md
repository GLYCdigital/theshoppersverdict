You'll learn your pitcher's sweet spot, but it takes time.

Also, the 20-ounce size is big. If you're making a single drink at home, this is overkill. You'll be steaming small volumes in a large pitcher, which makes texture control harder. The 12-ounce version addresses this, but if you already bought the 20, you're stuck compensating.

**Does the spout actually improve latte art?**
