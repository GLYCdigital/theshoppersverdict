This is a letter-size file jacket, not a standard manila folder. It measures 9-1/2" x 11-3/4" and features a straight-cut tab on the top edge. The "reinforced" part isn't just marketing jargon—Smead has added a translucent plastic strip along the top edge and the tab itself. You get a box of 25, and they come flat. There’s no printing, no color coding—just a clean, professional buff color that looks good in any setting.

**Build Quality and Real-World Performance**

In an era of flimsy, recycled-cardboard folders that disintegrate on contact, the Smead jacket feels reassuringly stiff. The 11-point stock is noticeably thicker than the standard 9-point folder you find at big-box stores. It holds up well if you’re carrying it around or shipping documents via interoffice mail.

The reinforced plastic strip is the star of the show here—it’s bonded well and doesn’t peel away from the paper edge, which is a common failure point on cheaper "reinforced" products.

**Where It Falls Short**

Let’s be honest about the downsides. First, the straight-cut tab is not the easiest to flip through quickly. If you’re a high-volume user, the standard "third-cut" tabs (which overlap in a staggered pattern) are far easier to scan. A straight cut means every tab is in the exact same position, so you’ll be reading the labels head-on, which takes more time.

Second, the "jacket" design holds only one stack of papers. If you want to separate sub-categories within a project, you’ll need multiple jackets. It’s not a folder with a pocket; it’s a flat sleeve. If you prefer to clip documents to the inside, you’ll find the front cover is a single sheet without a fastener.

Finally, the price per unit is slightly higher than a basic manila folder. You’re paying a premium for the reinforced top and heavy stock.
