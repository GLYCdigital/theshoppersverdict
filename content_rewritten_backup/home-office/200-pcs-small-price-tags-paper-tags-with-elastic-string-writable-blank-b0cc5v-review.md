## Where It Falls Short

Let's talk about the size. These are *small* tags — roughly 1.5 x 1 inch. If you're pricing furniture, large appliances, or anything needing a barcode or detailed description, you'll run out of space fast. A 0.5-inch label maker print will fit, but barely.

The attached elastic is also a double-edged sword. On delicate fabrics like silk scarves or thin knitwear, the loop can snag if you're not gentle. You can't remove the string and use these as pin tags — it's elastic or nothing. For a $7-ish pack of 200, that's a reasonable tradeoff, but know it going in.
