## Where It Falls Short

Let's be straightforward about the limitations. The lid is separate and not lockable. If you're stacking these unevenly or moving them in a truck, lids can shift. Plan on using tape or stretch wrap for anything beyond stationary storage.

Also, "medium-duty" isn't marketing language — it's a spec. These are rated for typical file weights (35–40 pounds). If you're storing dense legal reference books or heavy binders, you need the heavy-duty version. I've seen reviews complaining about box failure that, reading closely, involved people loading them with books. That's user error, not product failure.
