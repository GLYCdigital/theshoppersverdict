The 70540M is a folding hex key set with eight metric sizes: 1.5mm, 2mm, 2.5mm, 3mm, 4mm, 5mm, 6mm, and 8mm. The keys fold into a slim, textured handle that measures roughly 4.5 inches closed—small enough to drop in a pocket or toss in a tool bag without thinking about it.

The handle features a locking mechanism that holds each key firmly in place when deployed. You flip out the size you need, it clicks into position, and you're working. No magnetic retention gimmicks, no loose keys rolling under your workbench.

Klein Tools doesn't mess around with materials, and this set reflects that. The hex keys are forged from hardened steel with a black-oxide finish that resists corrosion and provides better grip than chrome-plated alternatives. I've used this set for everything from assembling furniture to adjusting bicycle components. The 8mm key handles moderate torque without flexing, and the smaller sizes work well in tight spaces where a full-size T-handle won't fit.

## Where It Falls Short

Let's be honest about limitations. The 8mm key is the largest size, so if you regularly work with 10mm or larger hex fasteners, you'll need a separate tool. The folding design also means you can't apply the same torque as you would with a full-size L-key or T-handle—the handle is shorter, so leverage is reduced.

Some users have noted that the keys can be stiff to deploy initially. It loosens up with use, but expect a break-in period. The black-oxide finish, while durable, will show wear and scratches over time—that's cosmetic, not functional.

The lack of a lanyard hole is a minor oversight. At this price point, a small hole for a tether would be a nice addition for those who work at heights or in awkward positions.
