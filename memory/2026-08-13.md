# Memory — 2026-08-13 (Thu)

## Website outage incident (major) — root cause + fixes

### Root cause
The Aug 7 "LLM rewrite of all 26k reviews" (deepseek-chat, commit `33a218ab1`) + the follow-up "comprehensive YAML cleanup" (`fc945538d`, Aug 7 09:45 SGT) broke the site in multiple ways:
- **7 static pages deleted** as collateral: `about.md`, `contact.md`, `affiliate-disclosure.md`, `privacy-policy.md`, `terms-of-service.md`, `newsletter.md`, `search.md`. All survived intact in `content_rewritten_backup/`.
- **Footer "lost"**: an UNCLOSED `<noscript>` in `layouts/index.html` (the 3 picks-col wrappers; the last one never closed) swallowed everything after it, including the footer.
- **Best-of page blank**: picks-col columns wrapped in `<noscript>`, so the client-side rotation JS found zero `.picks-col` DOM targets.
- **7 reviews with empty/broken placeholders**: 7 review files lost `title`/`slug`/`amazon_image`/`pros`/`cons`/`faq` (and some `review_count`) in the rewrite.

### Timeline
Site was broken ~6 days (Aug 7 → Aug 13) before Gabriel noticed. Last good deploy Aug 7 13:08 (`2b8c8c93f`).

## Lessons learned
- The "comprehensive YAML cleanup" script should NOT touch root-level `content/*.md` pages (only review files). qa_check.sh already skips parent_dir == "content".
- `wrangler pages deployment purge-cache` no longer exists in wrangler 4.x — purge must go through zone API (needs token scope) or dashboard.
- Cache headers: `_headers` sets `/* Cache-Control: public, max-age=0, must-revalidate`, but CDN edge still served a ~14h stale homepage until purged.
